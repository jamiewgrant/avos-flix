# CLAUDE.md

Context for Claude Code sessions working in this repo.

## What this is

**avos+flix** — a UK economic dashboard arguing, with data, that younger
generations' financial struggles aren't about discretionary spending. Wages
and asset prices on one chart, indexed to a chosen base year, with the
boomer rebuttals ("but interest rates were 15%", "but it's just inflation",
"skip the avocado toast") each pre-empted by a feature.

Live: https://avos-flix.vercel.app/

## Stack

- Vite + React 19 + TypeScript
- Tailwind v4 (theme tokens defined via `@theme` block in `src/index.css`)
- Visx for SVG charts; Framer Motion for transitions
- papaparse for CSV, xlsx for ONS spreadsheets
- tsx runs ETL scripts (Node 22+)
- Vercel for hosting; auto-deploys on push to main

## Commands

```bash
npm run dev        # vite dev server, http://localhost:5173
npm run build      # tsc -b && vite build — verifies type errors and prod build
npm run etl        # tsx scripts/etl.ts — fetches all sources, writes public/data/series.json
npm run lint       # eslint
```

`npm install` should use `--legacy-peer-deps` (set in `.npmrc`) because
Visx 3.x peer-deps cap at React 18 even though the library works with 19.

## Conventions

### Adding a data series

1. Create `scripts/sources/<name>.ts` with an async `fetchSeries(): Promise<Series>`.
2. Register the function in the `SOURCES` array in `scripts/etl.ts`.
3. If the upstream fetch can fail, fall back to a seed CSV in `scripts/seed/`.
4. If any portion is a modelled estimate or proxy, set `verifiedFrom: <year>` in the META — pre-`verifiedFrom` points render dashed.
5. Pick a distinct hex `color` (Tailwind-palette-style works well — see existing series for the palette in use).
6. Re-run `npm run etl` and commit the updated `public/data/series.json`.

### Data honesty principles (load-bearing)

- **Solid line** = ONS-published National Statistic or equivalent observed value
- **Dashed line** = modelled estimate, scaled proxy, or hand-curated historical figure
- **Don't fabricate pre-existence data.** Netflix didn't exist in the UK before 2012, retail avocados were negligible pre-2000 — both are kept as short lines starting at their actual UK introduction. Inflating them backwards would invent history and undermine the project's "undeniable data" stance. If asked again, refuse and offer the dashed-line / placeholder alternatives.
- **Don't quietly splice methodologies** — if you join two series with different methods (e.g. CPI 1949-1987 modelled + CPIH 1988+ Statistic), document it in the series description and use `verifiedFrom` to mark the boundary.

### Editing the chart

- Both `Chart.tsx` (indexed + raw modes) and `AffordabilityChart.tsx` use the same `splitAtVerified` helper to render estimated portions dashed. If you add a new chart, do the same.
- AnimatePresence wraps each series in `motion.g` keyed by series id. Don't break this — premature key collisions kill the toggle animations.

### URL state

`useUrlState` encodes `mode`, `baseYear`, `hiddenIds`, `realTerms`, and
`range` into search params. Defaults are omitted from the URL. To add a new
piece of state, extend the `UrlState` interface, `parseUrl`, and `stringify`
together.

## Known quirks

- **ONS XLSX URLs** sometimes 404 on `cdn.ons.gov.uk` even when WebFetch
  resolves them. Use `www.ons.gov.uk/file?uri=/...` as the primary host with
  `cdn.ons.gov.uk/file?uri=/...` as fallback. Set a browser-like
  `User-Agent` header — Node's default UA can be blocked.
- **datahub.io** redirects to `r2.datahub.io` for raw data files. Node's
  `fetch` follows the redirect automatically; WebFetch needs an explicit
  re-request.
- The **HM Land Registry HPI** URL is pinned to a snapshot month
  (`Average-prices-YYYY-MM.csv`). Bump it in
  `scripts/sources/landRegistry.ts` when a newer release supersedes it.
- The **Bank of England Bank Rate** doesn't serve a clean CSV at the BoE's
  own URL — we use the datahub.io mirror.
- **Building for Vercel**: `vercel.json` isn't needed; Vite auto-detects.
  `.npmrc` with `legacy-peer-deps=true` is required (Visx peer conflict).
